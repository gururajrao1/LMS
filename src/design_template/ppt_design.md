# Diagram-only semantic accents

Introduced for specific diagrams where category coding matters (soft, with dark equivalents):

| Purpose | Light | Dark |
| :--- | :--- | :--- |
| **"Bad/problem" (governance, sprawl)** | fill #F7E1E1 / text #C0392B | fill #3A1E1E / text #E88A8A |
| **"Good/runtime" (teal)** | fill #DCF0EA / text #1F8A6D | fill #12312A / text #4FC4A0 |
| **Agentic (mesh green)** | #E7F3EA / border #BFDCC8 | #18311F / border #2F5740 |
| **Procedural (mesh blue)** | #E3E9FB / border #C6D2F4 | #172647 / border #2C3C66 |
| **Capabilities (sand)** | #F5ECD6 / border #E3D6B0 | #2E2A18 / border #4C4526 |
| **Domain-data hexagons (green)** | #CDEBD6 / border #7BC49A | #1E4433 / border #3E7A5A |

**Ratio guidance (from the brand):** ~70% background · 20% ink · 8% grays · 2% accent — blue makes one decisive appearance per view; green stays scarce.
