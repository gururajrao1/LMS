# PharmaLearn decks

Create an editable `.pptx` from the supplied deck specification without adding factual claims.

## Select the template

- For an MSL learner, use `assets/MSL_Training_Deck_Template.pptx`.
- For an HCP learner, use `assets/HCP_Training_Deck_Template.pptx`.
- Never mix the two templates' colors, module structure, or audience framing.

## Build the deck

1. Treat the selected PowerPoint as the starting deck, not merely as inspiration.
2. Preserve its slide size, typography, palette, spacing, footers, page markers, and visual language.
3. Reuse the closest existing slide layouts and replace placeholders with the specification's content.
4. Keep the MSL deck scientifically detailed and evidence-boundary aware.
5. Keep the HCP deck practical, label-aligned, and focused on patient care.
6. Preserve claim-level citations in readable slide footers or reference areas.
7. Prefer concise copy over shrinking text. Remove unused placeholder slides rather than inventing content.
8. Return one final editable PowerPoint file and no additional deliverables.

## Guardrails

- Do not add efficacy, safety, comparative, dosing, or regulatory claims absent from the specification.
- Do not imply superiority from cross-trial comparisons.
- Keep MSL-only scientific-exchange nuance out of the HCP deck.
- Keep all remaining placeholders, clipping, and overlaps out of the final file.
