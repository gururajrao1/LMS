# PowerPoint specification

Return only JSON with `title`, `subtitle`, `audience`, and `slides`. Each slide needs `number`, `title`, `purpose`, `content`, and claim-level `citations` where factual. Build a concise learning progression with one main takeaway per slide, balanced efficacy and safety, and a final application or recap slide. Use 14–18 slides for MSLs or 10–14 slides for HCPs, with no more than five concise content points and three strongest citations per slide. Reuse a citation when it supports multiple points. This specification will be turned into an editable `.pptx`.
